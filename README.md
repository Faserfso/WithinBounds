# В пределах допуска / Within Bounds

Повесть. Социальная фантастика, написана в 2026 году.

Это рабочий репозиторий книги. Текст открыт для чтения и ещё вычитывается.

## Где что лежит

- `ru/` - главы, по одному файлу на главу. Обычный текст, разметка минимальная: `# ` перед названием главы, `*...*` для курсива.
- `metadata.yaml` - название, подзаголовок, аннотация.
- `assets/cover.png` - обложка.
- `build.sh` - сборка в DOCX, EPUB и FB2.

## Как править

**Мелкая правка.** Откройте главу в `ru/`, нажмите карандаш ("Edit this file"), исправьте, внизу нажмите "Commit changes".

**Большая вычитка.** На главной странице репозитория нажмите клавишу `.` (точку): откроется редактор в браузере с поиском по всей книге. После правок слева вкладка "Source Control", кнопка "Commit & Push".

**Через Claude.** Напишите в проекте, что поменять, правка придёт отдельным коммитом.

Любую правку видно в истории (`History` у файла) и её можно откатить.

## Готовые файлы

После каждой правки GitHub сам собирает книгу: вкладка **Actions** > последний запуск "Сборка книги" > внизу архив `v-predelah-dopuska` с DOCX, EPUB и FB2.

## Сайт-читалка

Папка `site/` собирает из глав сайт: оглавление, главы с навигацией, тёмная тема, размер шрифта, отметки прочитанного, кнопка «Слушать» (читает голосом устройства) и ссылки на EPUB, FB2 и DOCX. Сайт пересобирается и публикуется на GitHub Pages после каждой правки в `main`.

Чтобы публикация заработала, один раз: Settings > Pages > Source: **GitHub Actions**. Адрес сайта: https://faserfso.github.io/WithinBounds/

Собрать локально: `./build.sh && python3 site/build_site.py`, результат в `_site/`.
